# 领域边界

管理龙舟联赛队伍资格、混合组规则、分站成绩与总决赛积分。

## 参与方

- 赛事组委会 / 秘书处：注册、资格确认、替补审批、赛道调整、成绩更正、争议裁决、留痕
- 参赛队伍 / 队伍工作人员：报名、替补申请、申诉，仅可见本队数据
- 队员：以成员关系归属队伍，可被替补但关系保留
- 裁判：编排、提交/确认成绩（确认人须与提交人不同）、提出申诉
- 计时员：提交成绩，无权确认与晋级查询

## 实体与状态

- 成员关系：在队 / 已被替补 / 已离队；资格须秘书处确认
- 检录名单：检录即冻结，替补产生递增版本
- 替补：待秘书处审批 / 已批准 / 已驳回，携带理由与积分、晋级影响说明
- 场次：已编排 → 已收到成绩 → 已结算；出现异内容成绩或未决申诉时进入“积分锁定”
- 成绩接收：同内容幂等返回原记录；异内容追加为候选版本
- 积分台账：已确认 / 冻结未决 / 已作废，随成绩版本递增
- 申诉：未决 / 申诉成立 / 申诉驳回 / 撤回

## 关键约束

- 混合组 20 名划手中女子不少于 8 人；鼓手、舵手性别不计入女划手
- 前四个分站积分决定年度总决赛分组；锁定积分不计入确定排名
- 换人、赛道调整、成绩更正必须留下对积分与晋级影响的明确说明
- 内容不一致的重复成绩只锁定该场，其他组别照常结算
- 提交成绩的人不能独自确认争议；裁决人不得是任一候选版本的提交人
- 资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。
