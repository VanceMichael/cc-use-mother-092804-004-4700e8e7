# 领域边界

管理龙舟联赛队伍资格、混合组规则、分站成绩与总决赛积分。

现有领域资料围绕以下边界组织：

- 队伍与队员档案
- 组别资格校验
- 检录与替补
- 成绩和积分
- 晋级与申诉

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 赛事后台强制的规则

- 检录后名单冻结，替补只能按有效理由替换并保留原成员关系
- 重复接收同一场成绩返回原结果；内容不一致锁定该场积分，其他组别照常结算
- 提交成绩的人不能独自确认争议
- 换人、赛道调整、成绩更正必须由秘书处说明积分和晋级是否受到影响
- 裁判、计时员和队伍工作人员的可见范围不同
- 积分版本只增不减，晋级查询须能解释积分来源、组别资格、换人记录和未决申诉
