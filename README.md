# 龙舟联赛积分与混合组资格

管理龙舟联赛队伍资格、混合组规则、分站成绩与总决赛积分。

## 参与方与事实

主要参与方包括赛事组委会、参赛队伍、队员、裁判与计时员、积分管理员。领域资料记录以下已经确认的事实：

- 广州龙舟超级联赛第四站完成男子公开组和男女混合组比赛
- 混合组每队二十名划手中女子队员不少于八人
- 前四个分站积分决定年度总决赛分组

## 业务约束

- 队员资格
- 混合组比例
- 检录冻结
- 成绩申诉
- 积分版本

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/dragon_context.py` 负责读取和校验这些资料。

## 赛事后台

`src/league_backend.py` 提供赛事后台服务 `LeagueBackend`，领域模型与常量见 `src/league_model.py`，覆盖：

- 队伍注册、队员资格与组别规则（男子公开组、混合组二十名划手中女子不少于八人）
- 分站报名与检录冻结；冻结后替补只能按有效理由替换，并保留原成员关系
- 赛道与船只编排，赛道调整登记为影响事件
- 成绩接收幂等：重复提交同一内容返回原回执，内容不一致锁定该场积分，其他组别照常结算
- 成绩更正解除锁定并重新结算，积分版本只增不减
- 申诉处理：提交成绩的人不能独自确认争议
- 换人、赛道调整、成绩更正均须由秘书处说明积分和晋级是否受到影响
- 按角色（秘书处、裁判、计时员、队伍工作人员）过滤的场次视图
- 总决赛晋级解释：每支队伍的积分来源、组别资格、换人记录与未决申诉
